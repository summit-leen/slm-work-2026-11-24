# 图案版本登记（patterns/）

每个版本冻结成 `X_*.npy`（送 SLM 的 8-bit 数组，唯一权威来源）、同名 `.png`（1:1 图）、
`X_*_lenses.csv`（每枚透镜的 cx/cy/r/f/环数/边缘采样）。sha256 取 npy 的 `tobytes()`。

## 版本 B — 铺满面板的密集随机透镜阵列（黑底，无背景调制）

A 的随机噪声背景在反演模型里是无法用透镜 PSF 描述的未建模项，属于纯干扰。

| 项 | 值 |
| --- | --- |
| 文件 | `B_rla420_phase.npy` / `.png` / `B_rla420_lenses.csv` |
| 尺寸 | 1024×768 uint8，均值 69.55 |
| sha256（前 16 位） | `cd946d082f82244e` |
| 透镜 | **420 枚**，位置随机（RSA，与 A 逐枚相同） |
| 焦距 | 30.0–50.0 mm，420 个各不相同 |
| 口径 | 半径 9–43 px（0.32–1.56 mm） |
| 环数 | 0.4–10.2 个菲涅尔周期 |
| 覆盖 | **50.33%**（非零像素占比）；其余 49.67% 为 gray=0 |
| 生成 | `python code/random_lens_array.py --n 420 --f-min 30 --f-max 50 --gap 3 --margin 4 --seed 20261123 --save patterns/rla_dense` → 另存为 B |

**用途**：随机透镜阵列作为**编码孔径**做反演成像的输入图案；也作 A 的消融对照（只差背景调制）。

### B 作为成像编码器的定量上限（d=200 mm 物面）

`s_l = fd/(d−f)`，弥散 `Δ = √[(a|1−s/s_l|)² + (2.44λs_l/a)²]`，a 为口径直径，s=50 mm：

| 弥散直径 | 透镜数 | 占比 |
| --- | --- | --- |
| ≤ 50 µm | 0 | 0% |
| ≤ 100 µm | 12 | 3% |
| ≤ 150 µm | 63 | 15% |
| ≤ 200 µm | 233 | 55% |
| **中位** | **194 µm** | — |

在焦衍射斑（s=50 mm）：口径 0.90 mm → 84 µm；1.56 mm → 48 µm；0.48 mm → 158 µm。

**结论：用 B 反演，可恢复分辨率约 100–200 µm**（6.2 mm 视场 30–60 点），不是单透镜的 46 µm。
若要求全部透镜弥散 ≤46 µm（d=200），f 必须收在 37.9–41.7 mm（相对宽度仅 ±4%）。

## 版本 C — 单带微透镜 + 随机位置（稀疏）

| 项 | 值 |
| --- | --- |
| 文件 | `C_onezone_rand_phase.npy` / `.png` / `C_onezone_rand_lenses.csv` |
| 尺寸 | 1024×768 uint8，均值 11.66，非零 9.12% |
| sha256（前 16 位） | `7efaf3b7cfa75893` |
| 透镜 | **150 枚**，RSA 随机位置，互不重叠 |
| 焦距 | 30.06–49.97 mm（均值 39.88），150 个各不相同 |
| 口径 | 半径 **10.7–13.8 px（193–249 µm）**，由 `f = r²/(2λ)` 反解得到 |
| 环数 | **1.00**（每枚只有一个中心圆，无同心环） |
| 覆盖 | 9.1% |
| 艾里半径 | 59–76 µm（中位 68 µm） |
| 生成 | `python code/onezone_array.py --layout random --n 150 --f-min 30 --f-max 50 --seed 20261123 --save patterns/onezone_rand` |

**设计要点**：单带透镜的焦距与口径被 `f = r²/(2λ)` 焊死——要“只有一个中心圆”，口径就只能
取 193–249 µm（f 30–50 mm 对应）。代价是艾里半径从多带版（B，46 µm）涨到 68 µm，分辨率差 1.5×；
换来的是图案极干净（每枚就是一个亮盘，没有同心环）。

**用途**：需要“点阵干净、无衍射环”的实验（例如把阵列当分立点光源阵列、或当作稀疏采样网格）。
它是 B 的稀疏单带变体，不用于连续成像。

### C 的实测（2026-11-24）

| 项 | 值 |
| --- | --- |
| 帧 | `captures/ozrand_shot`（6 ms×16） |
| mean / max | 101.15 / 107.6（无饱和） |
| 结构 | **HP std 0.71 → 均匀** |
| 说明 | 拍摄时光路无点源、无物，阵列不起作用；有针孔点源时才会显出 150 个亮斑 |

**已知边界**：同 A/B——有效口径受 `r ≤ λf/2p` 限制，最大偏折角 λ/(2p)≈1°，NA ≤ 0.017。

### C 的 PSF 成像实测（2026-11-24，成功）

| 项 | 值 |
| --- | --- |
| 标定帧 h | 针孔 Ø100 µm，80 ms×16，`captures/C_psf_mean.npy`，**139 个亮斑**，核 FWHM 中位 41 px（82 µm） |
| 物帧 y | 2 mm 三角孔，1 ms×16，`captures/C_obj_mean.npy`，mean 60.5 / max 114.1 / 无饱和 |
| 几何一致性 | 两帧最亮 5 个点位置完全相同 → h 与 y 严格同几何 |
| 反卷积 | 局部实测核（61×61）+ Richardson–Lucy 30 次 |
| 效果 | 边缘宽度 229 px → **15 px（15×）**；50% 弦长 154 µm → 50 µm；三角边缘对比度 0.95 |
| 图 | `figures/C_deconv_result.png` |

**结论**：单带（C）的干净单峰 PSF 是本方案能反卷积的关键——多带版（B）的同心环会让 RL 震荡。

## PSF 反卷积对照实验（2026-11-24，决定"选哪个版本做反卷积"）

同一台系统、同一个 2 mm 三角孔，只改图案与标定同步性：

| 组 | 图案 | 几何是否一致 | 边缘 10–90% | 重建形态 | 结论 |
| --- | --- | --- | --- | --- | --- |
| ① | C（单带 150 枚） | ✅ h、y 同一次 | 229 → **15 px（15×）** | 清晰三角形，三边三角完整 | ✅ **成功** |
| ② | B（多带 420 枚） | ✅ h、y 同一次 | 19 → **8 px（2.4×）** | 有轮廓但碎成数块、带亮弧 | ⚠️ 能收敛，伪影明显 |
| ③ | B（多带 420 枚） | ❌ h 在 400 mm、y 在 217 mm | 无改善 | HP std 0.94 → 6.76，纯噪声放大 | ❌ 失败 |

注：①②的绝对数值不可横向比较（各自按动态范围归一化），只看组内改善倍数。

**结论**：
1. **几何一致是决定性的**——同一图案 B，标定不同步时完全失败，同步后立刻收敛（③→②）；
2. **PSF 形状是次要但真实存在的因素**——B 的核更小（46 µm vs C 的 82 µm），边缘能压到 8 px，但 5.4 个菲涅尔带带来的同心环旁瓣会让 RL 产生亮弧与碎片（②）；
3. 因此**做 PSF 反卷积应优先用单带（C）保证可逆性**；若要多带换分辨率，需要更强的正则（TV/去振铃）而不是裸 RL。

产出：`figures/C_deconv_result.png`（①）、`figures/B_deconv_result.png`（②）；原始帧在 `captures/{C_psf,C_obj,B_cal,B_obj}_mean.npy`（captures 不入库）。

## 版本 D — 纯随机相位（diffuser，无透镜）

| 项 | 值 |
| --- | --- |
| 文件 | `patterns/D_rand_phase.npy` / `.png` |
| 尺寸 | 1024×768 uint8，逐像素均匀随机，seed 20261124 |
| 均值 / std | 127.52 / 73.98；八分箱计数平坦（各 ~98k） |
| 相位行程 | 0–4.05 rad（用满 1.29π） |
| 自相关 | **1 px**（理想散射体） |
| sha256（前 16 位） | `e2e90dd1d7eacfa3` |
| 生成 | `python code/random_phase.py --seed 20261124 --block 1 --save patterns/D_rand` |

**用途**：diffuser 型无镜相机的编码器——PSF 是**全局**散斑场，每个物点铺满整靶面，理论上支持压缩感知、时间/光谱多路复用（与郑泽师兄 LPR/OL 那条线同族）。

### D 的实测（2026-11-24）

| 项 | 值 |
| --- | --- |
| PSF 帧（针孔） | `captures/D_cal_mean.npy`，80 ms×16，σ/μ **0.135**，颗粒 14 µm（7 px） |
| 物帧（2 mm 三角孔） | `captures/D3_obj_mean.npy`，300 ms×16，HP 2.46 |
| 反卷积 | RL 15/40 次**均塌缩成 delta**，Wiener 亦无效 |

### 结论：PSF 支撑必须 ≪ 物尺寸

反卷积 `y = x ⊛ h` 要求 h 的支撑远小于 x，否则无局部解：

| 图案 | PSF 支撑 | 物（2 mm 孔） | 支撑/物 | 结果 |
| --- | --- | --- | --- | --- |
| C 单带 | 82 µm | 2000 µm | 0.04 | ✅ 边缘 15× |
| B 多带 | 46 µm（带环） | 2000 µm | 0.02 | ⚠️ 可解但振铃 |
| **D diffuser** | **≈7.7 mm（满视场）** | 2000 µm | **3.9** | ❌ 塌成 delta |

D 的 PSF 支撑被靶面限死在 7.7 mm，因此要用 D 做单帧成像，物体必须 **≥20–30 mm**；而本 SLM 有效区仅 18.4×13.8 mm，**物理装不下**。
→ **本设备上 diffuser 不适合 2 mm 级物体的单帧成像，透镜阵列（C）才是正确选择。**

另：换成 2 mm 孔直照时散斑颗粒从 1.23 掉到 0.54（相干面积 λL/a = 124 µm ≪ 2 mm），必须先有针孔在物前提供相干照明，D 才可能编码。
